What is ABAP dictionary?

  • ABAP dictionary which is also called as Data dictionary.
  • Think of a big company which has thousand of employees, transactions, forms which contains employees name , orders data, date, material prices, everything.
  • Now someone has to decide where does each form look like where all the data gets stored in which field ? who decides the rules?
  • It is exactly what data dictionary means , it is the central part of SAP where all Domains, tables, structures are stored and defined.
  • Every table has name, field name, every data type exists anywhere in the SAP system

  • Note :- To use ABAP Dictionary we use Tcode- se11

How to open se11?


  1. Login into your SAP GUI account with user name and password.
  2. Find the command field which is there on the top on the left hand side. If not visible extend it.
  3. Type SE11 and press enter.
  4. The ABAP Dictionary initial screen opens. You'll see several radio button options — Database Table, View, Data Type, Type Group, Domain, Search Help, Lock Object

DataBase Tables ➖

A database table option is available when you open se11 transaction code

  • A table is a place that stores data in the form of rows and columns.
  • When a company stores employees names it is stored in table, when an order is created it is stores in table.
  • At last everything is stored in table.

Types of Tables:-

There are three of tables -

  1. Transparent table:-
  • In case of transparent table, there is 1:1 relationship between the ABAP dictionary and database.
  1. .Pooled Table:-
  • In case of pooled table there is N:1(Many to one) relationship between the ABAP dictionary and the database.
  • For pooled tables, primary-foreign key relationship is not required.
  1. Cluster Table:-
  • In case of transparent table, there is 1:1 relationship between the ABAP dictionary and database.
  • For cluster tables, primary-foreign key relationship is required.

What's inside a table? — Fields tab explained

When you open any table in SE11 and click the Fields tab, you see a list of columns. Here's what each column means:

Column What It Means
Field Name The actual name of the field.
Key Checked if this field is part of the primary key (unique identifier for each row).
Data Element The reusable definition that describes this field's type and labels.
Data Type The technical type — CHAR (text), NUMC (numbers), DATS (date), etc.
Length Maximum number of characters allowed in this field.
Short Description A plain English label for the field.   



What is Domain?

  • Domain describes the technical attributes of a field/column.
  • Technical attributes means data type and length. For eg- NUMC(10), CHAR(40).
  • Domains are linked to field via data elements.



What is Data Element?

  • Data element describes the appearance of field column to end user.
  • It provides a meaningful description to a field.



What is Primary- Key Foreign key relationship?

  • It is also called as parent-child relationship.
  • Primary key of one table acts as foreign key for another table.
  • For the relationship both of the table must have atleast one same column or attribute.
  • Number of records in one table corresponds to number of records in second table for a particular entry is called as cardinality.
