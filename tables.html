How to Create Tables in SAP ABAP: A Beginner's Step-by-Step Guide

In SAP ABAP, tables are used to store and organize data inside the SAP database. Almost every SAP application relies on tables to manage information such as employee records, customer details, sales orders, and product data.

What is a Table in SAP ABAP?

A table in SAP ABAP is a database object used to store structured data. Each table consists of:

  • Fields (Columns)
  • Records (Rows)
  • Primary Keys
  • Data Types

  • Tables must have a primary key which is used to identify a record uniquely.
 Note: The transaction code for creating a table is SE11

Why Do We Create Custom Tables?

SAP provides thousands of standard tables. However, organizations often have unique business requirements that cannot be fulfilled using standard tables alone.

Custom tables allow developers to:

  • Store company-specific information
  • Maintain custom application data
  • Create custom reports
  • Support business processes
  • Build industry-specific solutions
 Note: Custom table names should start with Z or Y.
Example: ZEMPLOYEE_TABLE

Important Components Required Before Creating a Table

There are 3 main components you should know before creating a table:

1. Domain

A Domain defines the Data Type, Length, and Value Range for a field.

Example: Char(40)

2. Data Element

A Data Element provides Field Labels used throughout the SAP system.

Example: ZDE_EMPLOYEE_NAME

3. Primary Key

  • A primary key uniquely identifies each record.
  • Example: Employee ID is the primary key.
  • Primary keys prevent duplicate records.

Step-by-Step Process to Create a Table in SAP ABAP

  1. Login into SAP GUI using your username and password.
  2. In the command field, enter Tcode SE11.
  3. Press Enter. The ABAP Dictionary screen will open.
  4. On the initial screen, select the Database Table radio button.
  5. Give a name for the table, e.g., ZEMP_TABLE.
  6. At the bottom of the screen, tap the Create button.
  7. Click on the Create button. A new screen will appear.
  8. Provide a Short Description for the table. E.g., Employee Table.
  9. Select the Delivery Class 'A'.
  10. Delivery Class determines how SAP manages table data during transport and upgrades.
  11. Set Maintenance Option to Display/Maintenance Allowed.
  12. Now create the required fields as shown in the table below.
Field Name Data Element Key

DEPARTMENT ZDE_DEPARTMENT No
DESIGNATION ZDE_DESIGNATION No
SALARY ZDE_SALARY No



Step 14: Now set the Technical Settings:

  • Set Data Class to APPL0
  • Set Size Category to 0
  • Save the settings.

Step 15: Save the table using CTRL+S.

Step 16: Activate the table by pressing CTRL+F3.




Understanding Technical Settings

Many beginners simply fill in values without understanding them. Here is a clear explanation of each technical setting.

Data Class

Determines the physical area where data will be stored.

Data Class Purpose
APPL0 Master Data
APPL1 Transaction Data
APPL2 Organizational Data

Size Category

Indicates the expected size of the table. For small tables, set this to 0.

How to Enter Data in a SAP ABAP Table Using SE16N

Step 1: Open Transaction SE16N

  1. Go to the SAP command field.
  2. Enter the transaction code: SE16N and press Enter.

Step 2: Enter the Table Name

In the Table field, enter your custom table name.

Example: ZEMPLOYEE_TABLE

Step 3: Access Table Data

The system will display the selection screen for the table.

To view existing records, press F8.

Step 4: Create a New Entry

  1. Click the Create Entry button.
  2. A new screen will appear showing all table fields.
  3. Enter values for each field.
  4. Fill in all required entries.

Step 5: Save the Record

  1. Click the Save button.
  2. SAP will validate the data.
  3. If no errors are found, the record will be stored in the table.
✅ A success message will appear confirming that the data has been saved.

Step 6: Verify the Data

To confirm the record has been inserted successfully:

  1. Return to the SE16N selection screen.
  2. Enter the table name.
  3. Click Execute (F8).

Conclusion

Creating a table in SAP ABAP is one of the basic but most important skills for any beginner. By learning how to create a custom table, define fields, set technical settings, and view or maintain data, you build a strong foundation for working with SAP applications. As you continue learning ABAP, tables will be used in almost every project you work on. With regular practice, the process becomes much easier and helps you understand how data is stored and managed within the SAP system.
