What is a domain?

  • A Domain in SAP is a important object used in ABAP dictionary. It is used in defining technical properties of a field such as data type, field length and value range.
  • It can be reused .
  • It is used to create data elements.

What is the starting letter to Initiate a domain?

  • To initiate a domain we have to mandatory use "Z" or "Y".
  • Mostly we use Z as our starting letter.
  • For eg- ZEMPID




How is domain reusable?

  • We can use same domain to create multiple fields and data elements.
  • For eg- we can use same domain for Student ID and Employee ID.


How Domain is appears in SAP?

In SAP domain controls:-
  • Data Type
  • Field Length
  • Number Format
  • Value Range
  • Allowed Values'




Why Do We Use Domains in SAP?

Domains are used because they provide:

1. Reusability
A single domain can be reused in multiple fields.

2. Consistency
All fields using the same domain will follow the same format.

3. Easy Maintenance
If changes are needed, they can be done in one place.

4. Data Validation
Domains help control the allowed values for a field.

Note-: To create a domain you should have already installed SAP GUI on your system and and know you user name and password.

Note:- Tcode for creating domain is [SE11].

Let's start creating the domain:-


Steps to create the domain :-

  1. Open SAP GUI and enter transaction code: se11.

  2. Select the radio button Domain.

  3. Enter a custom name for domain starting "Z" or "Y". for eg- ZEMPNAME.

  4. Click on create below.

  5. Enter the short description. For eg- "Employee Salary"

  6. Now enter the required fields.

  7. First enter the Data type you can choose and any data type from drop down menu on left hand side.Eg- NUMC,CHAR,CURR etc

  8. Now enter the number of characters for the data type. Eg- 5 for NUMC, 40 for CHAR.

  9. Now enter the number of decimal characters if needed.

  10. Now enter the value range if needed.

  11. Now save the Domain.

  12. Final step Activate it.
