Table Maintenance Generator
A Simple Step-by-Step Guide

Let users add, edit, and delete records in your custom tables — without writing a single extra line of ABAP code.

Tool  SE11 → Utilities
Test via  SM30
Level  Beginner–Intermediate

You already know how to make a table in SAP ABAP. Now it's time to learn about the Table Maintenance Generator (TMG). This is an essential tool in SAP that helps users update table data without writing extra ABAP code.

In projects, developers make custom tables to store business data. Just making a table is not enough. Users need a way to add, update, or delete records in that table. That's where the Table Maintenance Generator comes in.

What is a Table Maintenance Generator?

A Table Maintenance Generator is a SAP tool that automatically creates maintenance screens for a database table. These screens let users:

  • Add records
  • Edit existing records
  • Delete records
  • Display all table entries

Without the Table Maintenance Generator, developers would have to build custom programs and screens to update table data. This tool saves a lot of work by doing everything automatically.

Why Do We Use a Table Maintenance Generator?

Think about a custom table you made. Users need to add, change, or delete data in that table. A Table Maintenance Generator makes it easy for them to do exactly that.

🗂 Real-World Example

Suppose you have a custom table called ZEMPLOYEE (Employee Details) that stores:

  • Employee ID
  • Employee Name
  • Department
  • Salary

Instead of creating a separate program for data entry, use the TMG. SAP automatically generates an interface to add and edit records — saving you significant development effort.

This is why the Table Maintenance Generator is widely used in every SAP project.

Prerequisites

Before creating a Table Maintenance Generator, make sure:

  • SAP GUI is installed and working properly
  • A custom table already exists
  • The table has been activated successfully
  • You have permission to create development objects

Steps to Create a Table Maintenance Generator

Let's create a TMG step by step.

01

Open Transaction SE11

Go to the SAP command field and enter:

T-Code SE11

Press Enter. The ABAP Dictionary screen will open.

02

Enter Table Name

In the Database Table field, enter your custom table name.

Example: ZEMPLOYEE

Click Display. The table definition screen will appear.

03

Open Table Maintenance Generator

From the top menu, navigate to:

Utilities → Table Maintenance Generator
04

Maintain Required Fields

You will now see fields that need to be filled in.

Authorization Group

For beginners, enter: &NC&
This means no special authorization group is assigned.

Function Group

Enter a custom Function Group name starting with Z or Y.

Example: ZFG_EMP

Maintenance Type

Select: One Step — This is the most commonly used option.
05

Click Create

After filling all required information, click Create. SAP will generate the required maintenance objects automatically.

06

Save the Objects

A transport request popup may appear. Choose the appropriate transport request and save.

07

Activate the Generated Objects

Activate all generated objects. Once activation is successful, the Table Maintenance Generator has been created successfully. ✅

How to Test the TMG

Now let's see how to use the generated maintenance screen.

01

Open Transaction SM30

Go to the command field and enter:

T-Code SM30

Press Enter.

02

Enter Table Name

Enter your table name — for example, ZEMPLOYEE — and click Maintain.

03

Add New Records

The maintenance screen will open. Now you can:

  • Create new entries
  • Modify existing records
  • Delete records
  • Save data

All of this — without writing a single line of ABAP code.

Difference Between SE16 and SM30

Many beginners get confused between these two transaction codes. Here's a quick comparison:

Transaction Primary Purpose Can Edit Data?
SE16 Display and view table records View Only
SM30 Add, update, and delete records Full Maintain
💡
Quick Rule

If you want to change table data, always use SM30. For simply viewing or reporting on data, use SE16.

Real-Time Example

📌 Scenario

Suppose a company stores department information inside a custom table. Instead of asking developers every time a department changes, the company can create a TMG for that table.

Authorized users can then open SM30, enter the table name, and manage department records entirely on their own — no developer involvement needed.

Common Mistakes to Avoid

⚠️
Function Group Is Missing

You need to create or specify a Function Group before you can create a Table Maintenance Generator.

⚠️
Table Is Not Activated

Always make sure the custom table is fully activated before generating the TMG.

⚠️
Missing Development Permissions

Check that you have the correct authorization to create development objects in your system.

⚠️
Transport Request Not Selected

You must pick a transport request when saving the generated objects. Do not skip this step.

Best Practices

  • Always use names that start with Z or Y for custom objects
  • Activate the table before creating the Table Maintenance Generator
  • Use meaningful, descriptive names for Function Groups
  • Always test the generated screen using Transaction Code SM30
  • Verify you have the correct authorization in every system (Dev, QA, Prod)
